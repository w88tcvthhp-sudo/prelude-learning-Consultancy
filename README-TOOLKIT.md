# Book toolkit — setup and operation

Routes
- `/book-toolkit/` — access form (static `book-toolkit/index.html`, generated by build.py)
- `/book-toolkit/submit.php` — stores the request, sets the access cookie, redirects, sends the email
- `/book-toolkit/downloads/` — downloads page (`index.php`, gated, `noindex`)
- `/book-toolkit/download.php?f=<id>` — streams one file from the private folder

Hosting assumption: GoDaddy cPanel (Apache + PHP 7.4 or newer). Check PHP version in
cPanel > Select PHP Version. If the site ever moves to static-only hosting, these routes stop working.

## One-time setup (cPanel File Manager)
1. Create a folder **beside** `public_html` (not inside it): `prelude-private/`
   with sub-folders `toolkit/` and `data/`. Permissions 700.
2. Copy `book-toolkit/lib/config.example.php` to `prelude-private/config.php` and fill it in:
   - `secret`: a random string of at least 32 characters (e.g. from a password manager).
     Changing it later invalidates every existing access link.
   - `mail_from`: `jason.smith@prelude-learning.com` (must be a real mailbox on the domain).
   - `resend_api_key` (optional): if set, emails go via Resend (needs the domain verified
     with Resend's DNS records). If empty, PHP `mail()` on the host is used.
3. Upload the 22 toolkit files into `prelude-private/toolkit/` **with their original names**
   from the Online Toolkit Pack (e.g. `Tool-01_Training-Request-Challenge.docx`,
   `Tools-01-18_Combined-Workbook.docx`, `Template_Full-TNA-Report.docx`). The ready-made
   `prelude-private-upload.zip` already contains them in the right folder.
   Do **not** upload `00_Read-Me_Toolkit-Inventory-and-Landing-Page-Copy.docx` — it is internal.
   To replace a file later, upload a new version with the same name. No rebuild needed.
   If a file name or format changes, edit TOOLS / EXTENDED / COMBINED in build.py and rebuild;
   the manifest and download labels update together.

## Where data goes
- `prelude-private/data/toolkit-requests.csv` — every request (name, email, optional org/role, opt-in yes/no)
- `prelude-private/data/marketing-consent.csv` — only people who ticked the updates box, with the exact wording
- `prelude-private/data/email-failures.csv` — access emails that failed to send (follow up by hand)
- `prelude-private/data/ratelimit.json` — hashed, hour-long abuse counter; no addresses stored
Delete rows older than the retention period in the privacy policy (24 months).
